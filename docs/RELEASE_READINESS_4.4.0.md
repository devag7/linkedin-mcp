reviewed implementation with an identical tree. Runtime checks passed 843 tests

resolution or runtime changes beyond that reviewed implementation. Historical

## Required gates

1. Freeze the candidate; pass tests, lint, types, metadata and build. Retain
   evidence for legacy equivalence, explicit reference time, sorting, terminal
   states, null actions, row-local references, fractional dates and bounds.
2. Compare exact 15-file normal/ignore-scripts packages and fresh installed
   compiled/client checks. Audit source, fresh consumer and isolated publisher.
3. Obtain independent final-head review, 14 hosted CI passes and a source-pinned
   ten-job release dry run with mutation steps skipped. Pending/cancelled jobs
   are not passes; preserve any failures and retries separately.
4. Verify the merge tree and publish through the existing guarded main workflow,
   using OIDC only. No token fallback or parallel manual upload.
5. Independently verify npm bytes/SRI/signatures/provenance, scoped GitHub package
   file bytes/modes, active MCP Registry metadata and finalized Release/source tag.
6. Only then pin and build matching Claude packages; audit and probe both staged
   and unpacked archives, review their source and hosted results, upload without
   clobber, and verify public downloads/checksum companions. Native use and
   directory approval remain separate.

## Scope boundaries

No account access, login, application submission, individual outreach, native
extension installation or real-state deletion is authorized by this release
record. The [4.4.0 volunteer kit](FIRST_USE_VOLUNTEER_KIT_4.4.0.md) and
[results guide](FIRST_USE_RESULTS_4.4.0.md) prepare a separate zero-attempt cohort;
participants personally consent after public verification. The offline follow-up
queue and interview kit are excluded from its one-own-profile-read attempt.

Source/package checks do not establish native-client or live-provider behavior,
interview/follow-up usefulness, ownership of historical updater survivors or
completion of the full roadmap. No mandatory paid service is added.
